# 森の住民票アセット

`src/lib/forestResident/forestResidentAssets.ts` のパスと一致するファイル名で配置してください。

| ファイル | 用途 |
|----------|------|
| `forest_resident_card.png` | 住民票カード本体（枠・ラベル込み・720×720） |
| `forest_resident_badge_green.png` | バッジ（緑・新入り） |
| `forest_resident_badge_silver.png` | バッジ（シルバー） |
| `forest_resident_badge_gold.png` | バッジ（ゴールド） |
| `forest_resident_face_rabbit.png` | 顔アイコン（初期・うさぎ） |
| `forest_resident_body_rabbit.png` | 全身像（初期・うさぎ） |

背景透明化: `node scripts/forest-resident-transparentize.mjs`
