# 森の小さな音楽堂 — 音声ファイル

`src/lib/help/forestMusicHallCatalog.ts` の `src` パスと一致するファイル名で配置してください。  
**ファイル名は英数字（ASCII）推奨**です。曲名の日本語はカタログの `title` に書きます。

## 配置済み（BGM）

| ファイル | 曲名 | 用途 |
|----------|------|------|
| `bgm_resident_registration.mp3` | 森の案内所の日々 | 住民登録時のBGM |
| `bgm_intro_video.mp3` | 木漏れ日ワルツ | Life Journey Diary 紹介動画のBGM |
| `bgm_loghouse_build.mp3` | モグラの大工さん工事中 | ログハウス建築演出のBGM |
