## 配置済み（仮・約15秒）

| ファイル | 曲名 | 備考 |
|----------|------|------|
| `projector001.mp3` | 映写機の曲 1 | 仮。末尾を丸めた約15秒 |
| `projector002.mp3` | 映写機の曲 2 | 同上 |
| `projector003.mp3` | 映写機の曲 3 | 同上 |
