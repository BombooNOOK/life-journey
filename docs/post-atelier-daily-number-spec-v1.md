# 今日のすうじ投稿生成機能 仕様書 v1

> チャッピーくん策定版。リポジトリ保管用（2026-06-24）。

## 1. 目的

Life Journey Diary のSNSアトリエ内で、Instagram向けの毎日投稿
「あなたのすうじで読む 今日のこころ予報」
を生成できるようにする。

この投稿は、単なる数秘投稿ではなく、LJDらしい日記導線として設計する。

目的は以下。

* 毎日投稿しやすい投稿案を生成する
* 「今日のすうじ」と「あなたのすうじ」を組み合わせて、自分ごと化したメッセージを作る
* LJDの世界観、日記、どうぶつ鑑定士、すうじの読み解きをSNSに自然につなげる
* 最初はSNS投稿作成補助として使い、将来的にアプリ内表示や画像生成にも流用する

---

## 2. 表示上の言葉ルール

表に出す言葉は、LJDらしくやさしい表現に統一する。

### 使用する表現

* 今日のすうじ
* あなたのすうじ
* こころ予報
* おまもりカラー
* おすすめのすごしかた
* すうじ1のあなたへ
* すうじ2のあなたへ

### 表では原則使わない表現

* LP
* ライフパスナンバー
* ユニバーサルデー
* ユニバーサルナンバー
* 数字

ただし、2枚目の説明ページやキャプション内の補足として、小さく以下のように説明してよい。

* 今日のすうじには、ユニバーサルナンバーの考え方を使っています
* あなたのすうじには、ライフパスナンバーの考え方を使っています

内部実装上は `todayNumber`, `universalDay`, `lifePathNumber`, `LP` などを使用してよい。

---

## 3. 投稿構成

Instagramカルーセル投稿を想定する。

### 1枚目：表紙ページ

役割：今日のすうじと、その日の全体メッセージを見せる。

* シリーズタイトル：あなたのすうじで読む 今日のこころ予報
* 今日のすうじ（例：8）
* 表紙用メッセージ

### 2枚目：説明ページ

毎日生成しない。Canva / 背景画像で固定管理。

### 3枚目以降：個別ページ

今日のすうじ × あなたのすうじ の掛け合わせ。1ページに2ブロック。

* 3枚目：すうじ1・すうじ2
* 4枚目：すうじ3・すうじ4
* 5枚目：すうじ5・すうじ6
* 6枚目：すうじ7・すうじ8
* 7枚目：すうじ9・すうじ11
* 8枚目：すうじ22・すうじ33

各ブロック：見出し / サブ見出し / 本文 / おまもりカラー / おすすめのすごしかた 2項目

---

## 4. 生成対象

生成する：表紙メッセージ、個別メッセージ、おまもりカラー、おすすめのすごしかた、コピー用テキスト、投稿案保存データ

生成しない：2枚目説明ページ、Instagram自動投稿、SNS API、外部AI

---

## 5. 今日のすうじ計算ルール

投稿予定日から計算。既存投稿アトリエ実装に合わせる。

例：2026年6月25日 → `2+0+2+6+0+6+2+5=23` → `2+3=5` → 今日のすうじ = 5

月・日は2桁分解（6月24日 → 0+6+2+4）
