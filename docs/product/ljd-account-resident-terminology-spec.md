# Life Journey Diary｜アカウント・森の住民 用語基準

**Status:** Current Product Terminology / Source of Truth

## 製品の前提

Life Journey Diary（LJD）は、**1アカウント＝本人1人の人生記録**を基本とする。

家族・友人・旅行・飲食店等の思い出は、別の人物枠に日記を分けず、本人の「あしあと」として保存し、タグ等で整理する。

## 用語定義

### アカウント

ログイン・メールアドレス・認証・サービス利用主体・全データの所有単位。

**使う場面:** アカウント情報、メールアドレス、ログイン、セキュリティ、データ管理、アカウント削除、利用規約、プライバシーポリシー。

世界観よりも意味の正確性を優先する。

### 森の住民

LJD を利用している本人を、BambooNOOK の森の中で表す呼称。

### 住民登録

本人が初めて BambooNOOK の森へ入る際の登録体験の名称。

例: はじめての住民登録、森の住民登録。

登録後の日常操作や、アカウント削除を「住民登録をやめる」等と呼ばない。

### 森の住民票

`AccountSettings` にある住民番号・森でのおなまえ等を表示する、本人のカード。アカウント共通。

### Profile（内部実装）

内部のデータパーティション（`profile` / `profileId` 等）。

**ユーザー向け概念としては使用しない。** 一般 UI・案内・法務の人物切替用語にしない。

当面は削除・migration せず内部で維持する。新規利用者には Default Profile を1件自動確保し、その存在を意識させない。

管理者についてのみ、既存複数 Profile への切替互換を当面残す場合がある（新規作成はしない）。

## アカウント削除

ログインアカウントおよび、当該アカウントに紐づく保存データ（あしあと、鑑定、住民票設定、Profile 行、どんぐり台帳等）と認証情報を削除する操作。

ユーザー向け名称は **「アカウントを削除する」** とし、世界観的な婉曲で重大性を薄めない。

## 将来（参考・未実装）

家族・友人等の数秘鑑定は、現行 Profile 追加では提供しない。将来は「ほかの人を読み解く」等の独立機能として設計する想定。
